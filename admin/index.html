MESSAGERIE DU PORTFOLIO

Relier votre Gmail.

Cette liaison gratuite permettra d’envoyer vos réponses depuis Gmail et de les retrouver ici quand vos clients répondront.

Google vous demandera d’autoriser le script à envoyer des e-mails et à lire les fils des conversations du portfolio. Le script ne synchronise que ces conversations.

Le script est prêt et a été copié. Le code de connexion expire après 15 minutes.

  1. Ouvrez Google Apps Script dans un nouvel onglet.
  2. Remplacez le contenu de Code.gs par le script copié.
  3. Choisissez connectPortfolioEmail, cliquez sur Exécuter et autorisez Gmail sur le même compte que votre espace administrateur.

La synchronisation se fera automatiquement. Revenez ici : l’état se mettra à jour dès la première synchronisation.
